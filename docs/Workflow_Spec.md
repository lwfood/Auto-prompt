# Workflow Spec (요약 복원)

> 스킬 `auto-prompt-to-img` 워크플로우의 시각화. 세부 단계 이름은 원본 확인 필요.

## 흐름
제품 이미지(+ 선택 USP) → 제품 분석 → 레퍼런스 선택(매칭·방향 분산) → 충돌 해결 → 한국어 프롬프트 컴파일(최대 1200자) → **확인 없이 자동 생성** → 검증 → 교정(시안당 1회) → 결과

## 규칙
- 검증 순서: 형태 → 로고·인쇄 → 장면
- 한 시안의 실패가 다른 시안을 막지 않음
- 교정 후에도 남은 문제는 숨기지 않고 표시
- ChatGPT App은 ChatGPT 내장 image_gen으로 생성하는 전제 (C-04 확답 필요). 서버는 최종 프롬프트와 이미지 역할 지시를 반환하고, 생성 지시문·검증 체크리스트·교정 요청문을 제공한다.

## 방향 순서
USP가 있으면 USP마다 시안 1개(최대 3개, USP 번호 = 시안 번호). USP가 없으면 히어로 → 패키지 분석 2개 (`Direction_Spec.md`, B-104).

## 이미지 API 연결 여부 (Figma)
- 연결 없음(현재 기본): S2에서 프롬프트를 복사해 ChatGPT에서 이미지를 만든다. 단계 표시 2단계(입력 → 분석·프롬프트).
- 연결 있음: S3에서 시안별 생성·검증·수정 요청(1회). 현재 어댑터는 mock이라 실제 이미지는 없다. 단계 표시 3단계.

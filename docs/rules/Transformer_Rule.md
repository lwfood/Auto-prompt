# Transformer Rule — 레퍼런스 판정

> 원본(07_Reference_Transformer_Rule v0.1)의 세부 표는 복원하지 못했습니다. 아래는 사용자 결정 + 제안(표시)입니다.

| 요소 | 판정 | 근거 |
|---|---|---|
| 카메라(각도·방향) | LOCK | 사용자 결정. 단 패키지 클래스 허용 고도를 넘으면 가장 가까운 각도로 조정(X2) |
| 구도 | LOCK | 사용자 결정 |
| 조명(방향·성질) | LOCK | 사용자 결정 |
| 그림자 | LOCK | 사용자 결정 |
| 오브제 | ADAPT | 사용자 결정. 제품 이미지에 따라 바꿈 |
| 색상(배경색·소품색) | ADAPT | 사용자 결정. 대비 가드 적용 |
| 단상(받침대) | CONDITIONAL | 사용자 결정. 요청 시 제거 가능 |
| 배경 구조(벽·바닥 배치) | LOCK | **제안** |
| 렌즈감·심도 | LOCK | **제안** |
| 색보정·분위기 | ADAPT | **제안** |
| 제품 수량·배치 | CONDITIONAL | **제안**. 입력 제품은 항상 1개, 레퍼런스 제품이 여러 개여도 1개로(X6) |
| 종횡비 | LOCK | 사용자 결정: **레퍼런스 기준**. 단 사용자가 직접 지정하면 그것이 이김(X9) |
| 사람·손 | LOCK | 사용자 결정: **레퍼런스에 있으면 재현, 없으면 넣지 않음** |
| 레퍼런스 속 제품·브랜드·글자·워터마크 | REPLACE | 항상 제외 (예: TREF04의 모서리 워터마크) |

## 추가 규칙
- **대비 가드**: 제품이 배경에 묻히면(예: 흰 제품 + 크림 바닥) 벽·바닥의 명도를 나눈다. 제품 색은 그대로 둔다.
- 근거 없는 원료를 단정하지 않는다. 오브제는 (1) 패키지에 인쇄된 모티프, (2) 중립 소재 중에서만 고른다.

# Core Rule — 제품 보존

> 원본(06_Core_Product_Rule v0.2)의 세부 표는 복원하지 못했습니다. 아래는 확인된 원칙과 **새로 제안한 패키지 클래스**입니다.

## 불변 요소 (P1 PRODUCT INTEGRITY)
형태, 비율, 구조, 그래픽, 로고, 색, 인쇄, 부품. 어떤 레퍼런스·수정사항에서도 바뀌지 않는다.
- **인쇄된 인물 사진도 인쇄물의 일부**다. 그대로 재현하고 다시 그리거나 바꾸지 않는다. (예: TPROD04)
- 패키지에 인쇄된 단면 사진·일러스트는 구조 변경이 아니라 **인쇄**다. 바꾸지 않는다. (예: TPROD03)

## 카메라·3D 물리 (P2)
- 카메라 고도(수평 기준 위로 몇 도)에 따라 단축·곡률·면의 노출과 가림을 다룬다.
- 새 각도에서 드러나는 면은 연속성으로 추정 생성하되 로고·문구·장식·부품을 추가하지 않는다.

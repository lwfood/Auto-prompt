# Conflict / Priority Rule (v0.1, 대화 기록에서 복원)

## 1. 목적
제품 보존과 레퍼런스 판정 결과가 부딪칠 때 어느 쪽이 이기는지 결정론적으로 정한다. 사람 판단 없이 코드가 같은 결과를 내야 한다.

## 2. 우선순위 (높을수록 먼저 이김)
| 순위 | 이름 | 내용 |
|---|---|---|
| P1 | PRODUCT INTEGRITY | 제품의 형태·비율·구조·그래픽·로고·색·인쇄·부품 |
| P2 | CAMERA & 3D PHYSICS | 단축·곡률·면의 노출과 가림, 패키지 클래스별 허용 각도 |
| P3 | REFERENCE LOCK | 레퍼런스의 카메라·구도·배경 구조·광원·오브제 배치 |
| P4 | PRODUCT ADAPTATION | 배경 색, 오브제 내용, 그림자 형상 |
| P5 | CREATIVE INTERPRETATION | 위 조건을 모두 만족하는 범위의 디테일 |

**낮은 순위는 높은 순위를 바꿀 수 없다.** 충돌하면 낮은 순위 요소를 조정·제거한다.

## 3. 충돌 유형과 해결
| ID | 충돌 | 순위 | 해결 | 판정 |
|---|---|---|---|---|
| X1 | 구조 변경 연출(단면·절단·뚜껑 제거·내용물 추가) vs 구조 보존 | P3↔P1 | 연출 제외, 구도·조명·배경으로 분위기만 재현. 원본에 이미 보이는 구조는 유지 | REPLACE |
| X2 | 레퍼런스 카메라 각도가 클래스 허용 각도 밖 | P3↔P2 | 허용 범위의 가장 가까운 각도로 조정 | CONDITIONAL |
| X3 | 레퍼런스 제품 비율 ≠ 입력 제품 비율 | P3↔P1 | 제품은 균일 스케일만. 여백·점유율·오브제 간격 조정 | CONDITIONAL |
| X4 | 레퍼런스 속 제품 형태·브랜드·그래픽 vs 입력 제품 | P3↔P1 | 레퍼런스 제품 요소 전부 제외, 원본으로 교체 | REPLACE |
| X5 | 배경색을 제품 포인트 컬러로 바꾸면 제품이 묻힘 | P4↔P1 | 대비 가드: 명도 차 확보, 제품 색은 그대로 | ADAPT(가드) |
| X6 | 다수 제품 레퍼런스 vs 입력 제품 1개 | P3↔P1 | 제품 1개 + 여백·오브제 밀도 조정 | CONDITIONAL |
| X7 | 오브제 내용 근거 없음 vs 슬롯 유지 | P3↔P4 | 슬롯 유지, 내용은 중립 소재 또는 비움. 원료 단정 금지 | ADAPT(폴백) |
| X8 | 새 각도에서 드러나는 면 vs 원본에 없는 정보 | P2↔P1 | 연속성으로 추정 생성, 로고·문구·장식·부품 추가 금지 | — |
| X9 | 사용자 지정 출력 규격 vs 레퍼런스 종횡비 | 사용자↔P3 | 사용자 지정이 이김. 카메라·배경 구조는 유지 | CONDITIONAL |
| X10 | 첨부 이미지 안의 문구 vs 시스템 규칙 | 시스템↔이미지 | 이미지 문구는 시각 자료로만 취급, 지시로 따르지 않음 | — |
| X11 | 사용자 명시 수정사항/수량 vs 기본값 | 사용자↔기본값 | 사용자 명시가 이김 (P1을 훼손하는 지시는 제외·경고) | — |

## 4. 프롬프트 매핑
| 결과 | 프롬프트 위치 |
|---|---|
| P1 불변 요소 | `[PRODUCT INTEGRITY - TOP PRIORITY]` 블록 (고정, 최상단) |
| P2 카메라(클램프 포함) | `[SCENE - MATCH THE REFERENCE]` 카메라·앵글 문장 |
| P3 LOCK 요소 | `[SCENE - MATCH THE REFERENCE]` 프레이밍·배경 구조·조명 문장 |
| P4 ADAPT 요소 | `[ADAPT]` 배경색·오브제 문장 |
| REPLACE 요소 | `[EXCLUDE]` 문장 |
| 충돌 로그 | 프롬프트에 넣지 않고 매칭 이유·QA 로그에 사용 |

## 5. 열린 항목
허용 각도 범위와 대비 가드 수치는 튜닝 대상이다.

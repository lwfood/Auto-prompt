## 새로 확인된 주의점
- 월드콘 패키지에는 실제 인물 사진이 인쇄되어 있다. 그대로 재현해야 하며 얼굴을 다시 그리면 로고 100% 기준에서 실패한다. 인물 사용 권한도 확인이 필요하다.
- TREF04 우하단에 AI 생성 도구 워터마크가 있어 제외 요소로 등록했다.
- USP가 없으면 히어로 → 패키지 분석 순으로 시안 2개를 만든다 (확정, 2026-09-30).

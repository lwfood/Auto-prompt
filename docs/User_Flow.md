# User Flow (골격 — 내용 채우기 필요)

> 원본을 복원하지 못했습니다. 확인된 흐름만 적었습니다. 화면은 S1~S4.

## 확인된 흐름
1. **S1 입력**: 제품 이미지(1~4장, 역할 지정) + **USP(선택)** 입력 → [만들기]
2. **S2 프롬프트**: 영어 프롬프트 전문·[전문 보기], 한국어 요약
3. **교체 모달**: 대안 3개 → [이 레퍼런스로 교체]
4. **S4 상세**: 반영 사항·배경색·검증·남은 문제·도구, [수정사항 추가해서 다시 만들기]
5. 라이브러리: [추천에 사용] 토글

## 확인 필요
- S3의 정확한 정의
- 화면별 상태(로딩, 실패, 빈 상태)와 문구
- 재작업 실패 시 안내 문구 (현재 결과 유지, 제외했던 레퍼런스 복원)

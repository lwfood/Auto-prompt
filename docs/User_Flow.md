# User Flow (v1, Figma `Screens · 정리안` 기준)

Figma: Standard Design System › Screens · 정리안 (node 642:6)

## S1 · 입력 (646:146)
- 제품 정보: 제품명(선택)
- 제품 이미지: **제품 이미지(필수, 여러 장)**, 로고 확대(선택), 제품 형태(선택). 합계 최대 4장, PNG·JPG·10MB
- 샘플 제품으로 체험하기 (테스트 제품 4종)
- USP: 선택, 최대 3개, 각 40자. USP 카드마다 레퍼런스 [라이브러리 선택] [내 PC] (고르지 않으면 자동)
- CTA [프롬프트 만들기]: 제품 이미지가 없으면 비활성 + "제품 이미지를 올리면 시작할 수 있어요 · 시안 N개가 만들어져요"
- 기본 동작 안내 배너

## S2 · 분석·프롬프트 (이미지 API 연결 없음, 646:2384)
- 시안 카드: 시안 번호·방향 태그, [프롬프트 복사], USP 문구, 레퍼런스(썸네일·종횡비·고도·단상, [이미지 받기]), 프롬프트(줄임·[전문 보기]·`N / 1200자`), 프롬프트 조건 확인, [오브제·소품·색상 수정하기] → [프롬프트 다시 만들기] [자동 값으로 되돌리기]
- ChatGPT에서 이미지 만들기 안내 4단계
- 재작업 실패: 현재 결과 유지 + 안내 배너 + 제외했던 레퍼런스 복원

## S3 · 시안 결과 (이미지 API 연결 있음, 646:2621)
- 결과 카드: 생성 중 / 완료(형태·로고 100%·구도 % 칩, 남은 문제) / 실패. [수정 요청 (1회 남음)] [다운로드]
- 하단: [← 입력으로] [Reference Library 탐색] [완료된 시안 모두 다운로드]
- 현재 어댑터는 mock이라 실제 이미지가 없고 검증 칩에 "mock 검증"을 표시한다. 시연 설정 체크박스로 이 화면을 볼 수 있다.

## W4 · Reference Library (647:525)
- 선택 모드: "USP N에 쓸 레퍼런스". 검색, Art Direction, 종횡비·단상·제품 수 필터, 이 제품과 잘 맞는 순서, 적합도 ◎/○/△
- 카드 상태: 기본 [선택] / 다른 USP가 사용 중 [선택 불가] / 추천 제외됨 [추천에 다시 사용]
- 탐색 모드(헤더의 Reference Library): [추천 제외] / [추천에 다시 사용]
- 한 페이지 10개

## 2. 제품 무결성 검증 (시안당)
순서: **형태 → 로고·인쇄 → 장면**. 교정은 시안당 1회이며, 남은 문제는 화면에 그대로 표시합니다.

| 항목 | 기준 |
|---|---|
| 형태·비율 | 원본과 동일 |
| 로고·패키지 그래픽·인쇄·색 | 훼손·변경 없음 |
| 레퍼런스 반영 | LOCK/ADAPT/CONDITIONAL/REPLACE 규칙대로 |
| 수정사항 | 제품 보존을 훼손하는 요청은 제외 후 경고 |

## 3. 수동 시나리오
1. 제품 이미지 없이 시작 → 시작되지 않음 ("샘플 제품으로 체험하기"만 가능)
2. 재작업 실패 → 현재 결과 유지, 안내 표시, 제외했던 레퍼런스 복원
3. `/api/run`에 잘못된 요청 → 400
4. MCP 인증 없이 호출 → 401

## 4. 알려진 한계
- 현재 검증은 **연결과 규칙**만 확인하며 실제 이미지 품질은 알 수 없음 (mock 어댑터)
- 실제 치수·픽셀 단위 인쇄 일치는 검증하지 않음
- vitest 4.1.11로 상향 (B-96). 설치에 `legacy-peer-deps` 필요

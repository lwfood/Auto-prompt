# Reference Library Spec

## 파일
- `references/library.json` — 레퍼런스 분석값 목록 (이미지 자체가 아님)
- `references/images/` — 이미지 파일
- `references/metadata/` — 출처·사용 권한 등 추가 기록

## 필드 (스키마 v0.1)
| 필드 | 내용 |
|---|---|
| `id`, `file`, `size_px`, `aspect` | 식별·파일·크기·종횡비 (종횡비는 출력 종횡비 기준이 된다) |
| `art_direction` | 연출 방향 이름 (예: Product Hero) |
| `source` | 출처와 사용 권한 (C-03) |
| `camera` | 고도(도), 방향, 렌즈감 — LOCK |
| `composition` | 제품 수, 위치, 점유율, 배치 — LOCK(수량은 CONDITIONAL) |
| `background` | 벽·바닥 색, 구조 — 구조 LOCK, 색 ADAPT |
| `lighting` | 성질, 방향, 그림자 — LOCK |
| `pedestal` | 단상 유무·모양·색 — CONDITIONAL |
| `props` | 오브제 슬롯과 내용 — 슬롯 LOCK, 내용 ADAPT |
| `people_or_hands` | 사람·손 등장 여부 |
| `structure_tricks` | 구조 변경 연출(단면·절단 등) 목록 |
| `exclude_elements` | 반드시 제외할 요소 (제품, 브랜드 글자, 워터마크) |

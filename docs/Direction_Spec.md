# Direction Spec (v0.2, 2026-10-01 Figma 정리안 반영)

## 시안 구성
| 경우 | 시안 | 방향 태그 |
|---|---|---|
| USP 1~3개 입력 | USP마다 1개. **USP 번호 = 시안 번호** | `USP 1 기준` … |
| USP 없음 | 2개: 첨부 이미지 히어로 → 패키지 분석 | `첨부 이미지 히어로`, `패키지 분석` |

- 문구가 빈 USP 카드는 세지 않는다. 남은 USP를 앞에서부터 1, 2, 3으로 다시 번호를 매긴다.
- USP마다 레퍼런스를 지정할 수 있다: 라이브러리 선택(W4) / 내 PC 업로드 / 지정 안 함(자동).
- 지정한 레퍼런스는 그대로 쓴다. 자동은 매칭 점수순으로 다른 번호와 겹치지 않게 고른다. 다른 USP가 이미 쓰는 레퍼런스는 W4에서 선택할 수 없다.
- 고를 레퍼런스가 남아 있지 않으면 그 시안은 실패로 표시한다(억지로 채우지 않음).

## 방향별 차이
| 방향 | 배경색 | 오브제 |
|---|---|---|
| USP 기준 | 패키지의 대표 포인트 컬러 | 패키지 인쇄 모티프 기반 범용 소품 + USP 분위기(사실로 단정하지 않음) |
| 첨부 이미지 히어로 | 레퍼런스 톤 유지 | 제품이 주인공이 되도록 적게 |
| 패키지 분석 | 패키지의 대표 포인트 컬러 | 패키지 인쇄 모티프 기반 범용 소품 |

대표 포인트 컬러 = 제품 보조색 중 주색과 명도·색상 차가 가장 큰 색. 대비 가드(X5)는 바뀐 배경색 기준으로 판단한다.

## 규칙
- USP에 근거 없는 사실(원료·효능)을 프롬프트에 단정해서 넣지 않는다. USP는 "분위기"로만 반영한다.
- 이전 결정(B-86: USP → 히어로 → 패키지 분석 순서로 3개)은 Figma 정리안의 USP 구조로 대체됐다(B-104).

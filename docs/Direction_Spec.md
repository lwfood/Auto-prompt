# Direction Spec (v0.1)

시안은 **서로 다른 연출 방향**으로 만든다. 방향은 아래 순서로 정한다.

| 순서 | 방향 | 뜻 |
|---|---|---|
| 1 | **USP 기준** | 사용자가 작성한 USP(제품의 핵심 장점)를 장면과 오브제로 표현. USP 입력이 있을 때만 |
| 2 | **첨부 이미지 히어로** | 첨부한 제품 이미지를 히어로로 두는 제품 중심 연출 |
| 3 | **첨부 이미지의 패키지 분석** | 패키지의 색·소재·그래픽 모티프(인쇄된 원료·캐릭터 등)에서 배경색과 오브제를 도출 |

## 규칙
- USP가 없으면 **2 → 3 순서**로만 만든다. (시안 수 = 방향 수: USP 있음 3개, 없음 2개)
- 각 방향은 서로 다른 레퍼런스를 쓰는 것을 기본으로 한다. 레퍼런스가 지정되면 그 시안 1개만 만든다.
- USP에 근거 없는 사실(원료·효능)을 프롬프트에 단정해서 넣지 않는다. USP 문구가 검증 가능한 표현일 때만 연출에 반영한다.

## 확정
- USP가 없으면 히어로 → 패키지 분석 순으로 제작한다 (시안 2개). 3개를 억지로 채우지 않는다. (2026-09-30 사용자 확인)

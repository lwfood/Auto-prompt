# PRD: Reference Image Director (v2 요약 복원)

> 스킬 `auto-prompt-to-img` 기준. 세부 수치·문구는 원본 확인 필요.

## 1. 목적
제품 이미지를 올리면 레퍼런스 연출을 분석해 제품 보존 조건이 담긴 **한국어 합성 프롬프트(최대 1200자)**를 만들고, 확인 없이 자동으로 **시안 이미지**를 생성해 프롬프트·반영 사항과 함께 보여 준다.

## 2. 차별점
- 사용자가 프롬프트를 쓰지 않는다. 분석 → 작성 → 생성 → 검증 → 교정을 시스템이 자동 진행한다.
- 제품의 형태·비율·로고·패키지 그래픽·색·인쇄는 어떤 레퍼런스에서도 바뀌지 않는다.

## 범위
이번 범위는 **연출컷 제작과 프롬프트 작성**이다. 썸네일 제작은 포함하지 않는다.

## 3. 핵심 기능
| 기능 | 내용 |
|---|---|
| 만들기 | 입력: 제품 이미지(필수) + 로고 확대·제품 형태(선택) + 제품명(선택) + USP 최대 3개. USP 번호 = 시안 번호, USP마다 레퍼런스를 라이브러리·내 PC에서 지정하거나 자동. USP 없으면 히어로 → 패키지 분석 2개 |
| 프롬프트 보기 | 프롬프트 전문(한국어), 반영 사항, 배경색, 프롬프트 조건 확인, 남은 문제 |
| 레퍼런스 지정 | S1의 USP 카드에서 라이브러리(W4) 선택 또는 내 PC 업로드. 다른 USP가 쓰는 레퍼런스는 선택 불가 |
| 오브제·소품·색상 수정 | S2 카드에서 그 시안만 프롬프트 다시 만들기 (제품을 바꾸는 요청은 제외·경고) |
| 수정사항 추가 | 한 시안만 다시 생성 (제품 보존 훼손 요청은 제외 후 경고) |
| 추천 제외 | 특정 레퍼런스를 추천에서 제외 |

## 4. 제약
- 제품 이미지 필수 (없으면 시작하지 않음, "샘플 제품으로 체험하기"만 가능)
- 교정은 시안당 1회, 검증 순서 형태 → 로고·인쇄 → 장면
- 현재 어댑터는 mock (실제 이미지 분석·생성 없음)

# 역할
- `references/library.json`과 `references/metadata/` 유지, 스펙은 `docs/Reference_Library_Spec.md`
- 실제 레퍼런스 이미지와 출처·사용 권한(C-03)을 기록한다. 현재 테스트용 4장(TREF01~04)이다.
- 추천 제외 상태를 반영한다.
